# Прогнозирование спроса на новогодний ассортимент розничной сети

## в разрезе «магазин × товарная подгруппа» для оптимизации первичного распределения

---

### 1. Бизнес-проблема

Розничная сеть товаров для дома, декора и подарков (170+ магазинов по России) ежегодно распределяет новогодний ассортимент по магазинам на основе экспертной оценки менеджера товародвижения. Решение о первичном распределении принимается в середине октября, когда товар уже на складе, но продажи ещё не начались. Ошибки распределения приводят к двум видам потерь:

- **Недовоз (out-of-stock):** магазин распродал товар досрочно, полка пустует, продажи упущены.
- **Перевоз (overstock):** после 31 декабря непроданный сезонный товар замораживает оборотные средства и требует уценки.

Цель проекта — на основе данных за два новогодних сезона (2024 и 2025) построить статистически обоснованные правила распределения товара и оценить, насколько они точнее текущей практики.

---

### 2. Постановка задачи

**Единица прогноза:** магазин × товарная подгруппа × сезон (ноябрь–декабрь).

**Целевая переменная:** суммарные продажи в штуках за основной сезон.

**Точка отсечки признаков:** 15 октября — модель использует только информацию, физически доступную до начала продаж. Это гарантирует отсутствие утечки данных.

**Метрика качества:** WAPE (Weighted Absolute Percentage Error) — взвешенная абсолютная процентная ошибка. Выбрана вместо MAPE, поскольку в данных много ячеек с низкими или нулевыми продажами, на которых MAPE уходит в бесконечность. Дополнительно оценивается bias (систематический пере-/недопрогноз).

**Методы прогноза** (три, для сравнения):

1. **Наивный LFL-прогноз:** факт продаж этого магазина по этой подгруппе за сезон 2024 × коэффициент роста сети.
2. **Fair share:** доля магазина в сетевых продажах × суммарный прогноз по подгруппе.
3. **Ridge-регрессия:** линейная модель с регуляризацией, подбирающая отдельные веса для признаков (кластер, категория магазина, товарная подгруппа, дефицит прошлого сезона) вместо единого коэффициента роста.

**Прогноз строится в натуральном выражении (штуках),** поскольку решение о распределении принимается в единицах. Денежное выражение (рубли) используется для приоритизации подгрупп и оценки экономического эффекта.

---

### 3. Данные

**Источник:** 36 недельных выгрузок из учётной системы 1С, подготовленных вручную.

**Период:** по 18 недель на сезон (W40–W05), охватывающих октябрь–январь 2024/2025 и 2025/2026.

**Гранулярность:** магазин × SKU × неделя. Каждая строка содержит остаток на конец недели, продажи (шт. и руб. с НДС), факт отгрузки со склада, атрибуты магазина и товара.

**Объём:** 3 441 294 строки, 172 магазина, 1 572 SKU, 83 товарных подгруппы.

**Обезличивание:** выручка масштабирована коэффициентом в целях конфиденциальности; все относительные величины сохранены. Данные не публикуются в репозитории.

### 4. Что сделано (Блоки 1–10)

#### Блок 1. Инициализация
Импорт библиотек, настройка путей, функция автоматического разбора имени файла в (год, неделя, сезон).

#### Блок 2. Загрузка и консолидация
36 файлов Excel прочитаны в цикле, размечены по сезонам, объединены. Итог — 3 441 294 строки × 20 колонок.

#### Блок 3. Первичная проверка целостности
Пять автоматических проверок: полнота недель (18+18 — ОК), стабильность колонок, состав магазинов по сезонам, пропуски в ключевых полях (0), типы данных.

#### Блок 4. Очистка и преобразование
Заполнение пропусков нулями (обосновано сверкой на конкретном примере), приведение даты открытия к datetime (устранена проблема смешанных форматов), нормализация регистра подгрупп (85 → 76), составной ключ подгруппы (83 уникальных), 0 дубликатов, справочник магазинов собран из данных.

#### Блок 5. Конструирование признаков и агрегация
Правило `ever_active` (99.9% пар в ассортименте), флаг дефицита `is_stockout` (4.3% дефицитных наблюдений), функциональные окна (october / season / january), агрегация SKU → подгруппа, коэффициент роста сети (0.945), признак «новый магазин».

#### Блок 6. Исследовательский анализ данных (EDA)
Описательная статистика (среднее/медиана 3.69 — сильная скошенность), динамика продаж по неделям с определением пика по данным (неделя 52 в обоих сезонах), сравнение сезонов, распределение дефицита по кластерам (Дальний Восток — 25.7%, аномалия), ABC-XYZ анализ по подгруппам.

#### Блок 7. Статистический анализ и проверка гипотез
- Устойчивость рангов подгрупп между сезонами: Спирмен ρ = 0.906 (p < 0.0001) — обосновывает методологию LFL-прогноза.
- Дефицит на Дальнем Востоке значимо выше остальной сети: тест Манна-Уитни, p < 0.00001, в 5.2 раза выше среднего.
- Категория магазина статистически связана с дефицитом (χ² = 532.87, p < 0.00001), но практический эффект слабый (разброс 6.0 п.п.) — пример разграничения статистической и практической значимости.

#### Блок 8. Прогноз — бейзлайны
Временно́е разбиение train (2024) / test (2025). Наивный LFL и fair share дали идентичный результат (WAPE 50.0%, bias +16.3%) — математически тождественны при едином коэффициенте роста. На Дальнем Востоке — почти двукратный недопрогноз (bias −88.1%), связанный с занижением исторических продаж из-за дефицита. Точность прогноза выше для стабильных доходных подгрупп (AY: WAPE 36.7%) и ниже для хаотичных малозначимых (CZ: WAPE 69.0%).

#### Блок 9. Итоговые результаты
Агрегированный отчёт по метрикам, таблица рекомендованного распределения (`recommended_distribution.csv`), оценка упущенной выручки на Дальнем Востоке (306 883 руб. в масштабированных цифрах), бизнес-рекомендации, зафиксированные ограничения.

#### Блок 10. Ridge-регрессия
Честное разбиение train/test **по магазинам** (0 пересечений), отдельная проверка на 36 отложенных магазинах, не участвовавших в обучении. Бейзлайны пересчитаны на той же контрольной выборке для корректного сравнения.

**Результат:** Ridge-регрессия существенно точнее обоих бейзлайнов — WAPE снизился с 51.7% до **33.5%** (−18.2 п.п., относительное сокращение ошибки на треть), bias сократился почти втрое (16.4% → 6.2%). Улучшение системное — Ridge точнее бейзлайна в 8 из 9 кластеров. Значимые признаки интерпретируемы: наибольший положительный эффект — подгруппы категории «сладости» и «упаковка», наибольший отрицательный — категория магазина E (наименьший формат). Ridge-регрессия принята как основной метод прогноза; бейзлайны сохранены в проекте как интерпретируемая отправная точка и инструмент диагностики.

### 5. Ключевые методологические решения

| Решение | Обоснование |
|---------|-------------|
| Анализ на уровне подгруппы, а не SKU | Решение о распределении принимается по товарной матрице; SKU обновляется между сезонами, подгруппы сопоставимы |
| Продажи ≠ спрос: коррекция на дефицит | Флаг `is_stockout` фиксирует недели, когда продажи занижены из-за отсутствия товара |
| Косвенное правило `ever_active` вместо справочника ассортимента | Справочник планового ассортимента недоступен; ограничение зафиксировано |
| Коэффициент роста — по октябрю, до начала сезона | Исключает утечку данных: величина известна на 15 октября |
| WAPE вместо MAPE | Устойчивость к низким/нулевым продажам |
| Разбиение train/test по магазинам (Блок 10) | Гарантирует, что модель не «видела» проверочные магазины ни в каком виде |
| Масштабирование признаков обучено только на train | Исключает утечку информации о проверочной выборке в обучение |
